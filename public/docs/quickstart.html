Quickstart

Go from zero to your first answer from Kaal: create a key, add credits, start a consultation, read the answer and ask a follow-up.

  1. Create an API key

    Sign in and open the developer dashboard. Click Create key, give it a name and copy it. The key is shown only once.

    Store it in an environment variable on your server:

    export KAALERA_API_KEY="kal_live_..."

  2. Buy credits

    On the same dashboard, buy a credit pack (2, 10 or 50 credits). Each question costs 1 credit, including the first question of a consultation. Check your balance at any time:

    curl {BASE}/v1/balance \
  -H "Authorization: Bearer $KAALERA_API_KEY"

  4. Poll for the answer

    Answers usually take a few minutes. Poll every 10 seconds until status is ready and the last message has role: "kaal".

    # Repeat every 10 s until status is "ready" and the last message has role "kaal"
curl {BASE}/v1/consultations/6e241e38-dd8f-428b-ae09-a8d7169335d3 \
  -H "Authorization: Bearer $KAALERA_API_KEY"
    const headers = { Authorization: `Bearer ${process.env.KAALERA_API_KEY}` };
const id = "6e241e38-dd8f-428b-ae09-a8d7169335d3";

async function waitForAnswer() {
  while (true) {
    const res = await fetch(`{BASE}/v1/consultations/${id}`, { headers });
    const { consultation } = await res.json();
    if (consultation.status === "failed" || consultation.status === "closed") throw new Error(consultation.status);
    if (consultation.status === "ready") {
      const last = consultation.messages.at(-1);
      if (last?.role === "kaal") return last.content;
    }
    await new Promise((r) => setTimeout(r, 10_000)); // poll every 10 s
  }
}

console.log(await waitForAnswer());

  5. Ask a follow-up

    Ask another question in the same consultation. You can switch the answer language with any question; the new language also becomes the consultation default.

    curl -X POST {BASE}/v1/consultations/6e241e38-dd8f-428b-ae09-a8d7169335d3/questions \
  -H "Authorization: Bearer $KAALERA_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
  "question": "Is the window after March 2027 better for starting my own business?",
  "language": "Hinglish"
}'

!

Call the API from your server only. Never put an API key in browser or mobile app code.
