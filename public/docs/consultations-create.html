Create a consultation

Computes the birth chart and asks Kaal the first question. Costs 1 credit.

POST/v1/consultations

Request body

fullNamestringrequired

Full name of the person. Up to 120 characters.

genderstringrequired

One of Male, Female, Other.

dateOfBirthstringrequired

Date of birth, e.g. "2 Sep 1990".

timeOfBirthstringrequired

Local time of birth, e.g. "5:24 PM". The more exact, the better the house placements.

placeOfBirthstringrequired

Place of birth as "City, State, Country", e.g. "Jaipur, Rajasthan, India".

timezonestringrequired

IANA time zone of the birth place, e.g. "Asia/Kolkata".

latitudenumberoptional

Latitude of the birth place, −90 to 90. Recommended. If omitted, the place is geocoded from placeOfBirth.

longitudenumberoptional

Longitude of the birth place, −180 to 180. Recommended together with latitude.

languagestringoptional

Language Kaal answers in. Defaults to English. See Languages.

questionstringrequired

The first question, 2 to 600 characters.

Request

curl -X POST {BASE}/v1/consultations \
  -H "Authorization: Bearer $KAALERA_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
  "fullName": "Asha Verma",
  "gender": "Female",
  "dateOfBirth": "2 Sep 1990",
  "timeOfBirth": "5:24 PM",
  "placeOfBirth": "Jaipur, Rajasthan, India",
  "timezone": "Asia/Kolkata",
  "latitude": 26.9124,
  "longitude": 75.7873,
  "language": "English",
  "question": "When is a good window for a career change?"
}'

consultation.idstring

Consultation ID. Use it to poll and to ask follow-ups.

consultation.namestring

The fullName you sent.

consultation.languagestring

Default answer language for this consultation.

consultation.statusstring

Session state, starting or ready. The answer itself arrives later; see Get a consultation.

consultation.created_atstring

ISO 8601 timestamp.

consultation.expires_atstring | null

When the consultation closes (7 days after it starts). After that it is read-only.

credits_remaininginteger

Your credit balance after this request.
