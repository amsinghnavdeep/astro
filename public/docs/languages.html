Languages

Kaal can answer in nine languages. Astrological terms such as house, dasha and nakshatra names may stay in their usual form.

Supported values

Pass one of these exact values (case-sensitive) as language:

ValueNotes
EnglishDefault
HindiDevanagari script
HinglishHindi in Latin script, mixed with English
Punjabi
Bengali
Marathi
Gujarati
Tamil
Telugu

Setting the language

  • Per consultation: set language in Create a consultation. It defaults to English.
  • Per question: set language in Ask a follow-up to switch language mid-consultation. The new language applies to that answer and becomes the consultation default for later questions.
{
  "question": "Is the window after March 2027 better for starting my own business?",
  "language": "Hinglish"
}

An unsupported value returns 400 invalid_request.
