Errors & limits

Errors use standard HTTP status codes and a stable, machine-readable code.

Error format

{
  "error": {
    "code": "insufficient_credits",
    "message": "Not enough API credits. Buy more at /developers."
  }
}

Branch on error.code; error.message is for people and may change.

Retrying

  • 503 unavailable: retry with backoff (for example after 30 s, then 60 s).
  • 429 answer_pending: poll the consultation and ask again once status is ready.
  • 409 consultation_closed: start a new consultation; closed ones cannot be resumed.
