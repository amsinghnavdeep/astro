Ask a follow-up

Asks another question in an open consultation. Kaal keeps the Kundli and earlier answers in mind. Costs $6.30 from your API wallet.

POST/v1/consultations/:id/questions

Path parameters

idstringrequired

The consultation ID.

Request body

questionstringrequired

The question, 2 to 600 characters.

languagestringoptional

Answer language for this question and the ones after it (it also updates the consultation language). Defaults to the current consultation language. See Languages.

Request

curl -X POST {BASE}/v1/consultations/6e241e38-dd8f-428b-ae09-a8d7169335d3/questions \
  -H "Authorization: Bearer $KAALERA_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
  "question": "Is the window after March 2027 better for starting my own business?",
  "language": "Hinglish"
}'
const res = await fetch("{BASE}/v1/consultations/6e241e38-dd8f-428b-ae09-a8d7169335d3/questions", {
  method: "POST",
  headers: {
    Authorization: `Bearer ${process.env.KAALERA_API_KEY}`,
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
  "question": "Is the window after March 2027 better for starting my own business?",
  "language": "Hinglish"
}),
});
const data = await res.json();
console.log(res.status, data);
import os, requests

res = requests.post(
    "{BASE}/v1/consultations/6e241e38-dd8f-428b-ae09-a8d7169335d3/questions",
    headers={"Authorization": f"Bearer {os.environ['KAALERA_API_KEY']}"},
    json={
      "question": "Is the window after March 2027 better for starting my own business?",
      "language": "Hinglish"
    },
)
print(res.status_code, res.json())

question_idstring

ID of your question. It appears as a user message in the consultation.

statusstring

Always answering.

balance_centsinteger

Your wallet balance in US cents after this request.

Then poll Get a consultation until status is ready again.

i

You can have at most 2 unanswered questions in a consultation at a time. A third returns 429 answer_pending.
