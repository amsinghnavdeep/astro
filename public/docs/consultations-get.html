Get a consultation

Returns the consultation with its full message history. Poll this endpoint to receive Kaal's answers. Free.

GET/v1/consultations/:id

Path parameters

idstringrequired

The consultation ID returned by Create a consultation.

The kaal message above is shortened; real answers are a few thousand characters of Markdown.

consultation.statusstring

See status values.

consultation.messagesarray

All messages, oldest first.

messages[].idstring

Message ID. For your questions it equals the question_id returned when you asked.

messages[].rolestring

user (your question) or kaal (an answer).

messages[].contentstring

Message text. Kaal’s answers are Markdown.

messages[].created_atstring

ISO 8601 timestamp.

The other fields (id, name, language, created_at, expires_at) are the same as in Create a consultation.

Status values

StatusMeaning
startingKaal is being set up for this consultation.
answeringAt least one question is waiting for an answer.
readyAll questions are answered. You can ask a follow-up.
closedThe consultation is more than 7 days old. Read-only; create a new one to ask more.
failedThe consultation could not continue. Unanswered questions are not charged.

Polling

Answers usually take a few minutes. Poll every 10 seconds and stop when status is ready, closed or failed.

const headers = { Authorization: `Bearer ${process.env.KAALERA_API_KEY}` };
const id = "6e241e38-dd8f-428b-ae09-a8d7169335d3";

async function waitForAnswer() {
  while (true) {
    const res = await fetch(`{BASE}/v1/consultations/${id}`, { headers });
    const { consultation } = await res.json();
    if (consultation.status === "failed" || consultation.status === "closed") throw new Error(consultation.status);
    if (consultation.status === "ready") {
      const last = consultation.messages.at(-1);
      if (last?.role === "kaal") return last.content;
    }
    await new Promise((r) => setTimeout(r, 10_000)); // poll every 10 s
  }
}

console.log(await waitForAnswer());
import os, time, requests

headers = {"Authorization": f"Bearer {os.environ['KAALERA_API_KEY']}"}
cid = "6e241e38-dd8f-428b-ae09-a8d7169335d3"

while True:
    c = requests.get(f"{BASE}/v1/consultations/{cid}", headers=headers).json()["consultation"]
    if c["status"] in ("failed", "closed"):
        raise RuntimeError(c["status"])
    if c["status"] == "ready" and c["messages"][-1]["role"] == "kaal":
        print(c["messages"][-1]["content"])
        break
    time.sleep(10)  # poll every 10 s
